# Printer profiles

An optional feature. By default b123d-print is in **generic mode**: no printer assumed, 0.8 mm
minimum wall, 45° overhang limit, no build-volume check. Setting a printer only adds facts that
change how a part is *modeled*; no slicer tuning (speeds, elephant foot, bridges, first layer).

```bash
b123d-print printer list bambu a1        # search 405 printer models
```

```bash
b123d-print printer use bambu_lab_a1_mini --material petg
```

- Parts must then fit the build volume in print orientation (`fit` check; it fails otherwise,
  and warns when the part only fits turned 90°).
- Minimum wall becomes 2 line widths of your nozzle; the overhang limit comes from the printer;
  material notes (PLA vs PETG vs ASA …) reach the model.
- `b123d-print printer hole-comp 0.4` stores your [coupon result](hole-compensation.md) for that
  printer + material.
- `b123d-print printer show` shows the active printer; `b123d-print printer use generic` goes
  back.
- Over MCP: the `use_printer` tool searches and sets them; `list_parts` shows the active ones.

## What a profile holds

- **Printer:** build volume (round beds by diameter), nozzle, layer height (0.2 unless set),
  overhang limit (45° unless set). Derived: line width ≈ 1.125 × nozzle, minimum wall = 2 lines.
- **Material:** label, notes for the model, optional clearance. Built-in: pla, petg, asa, abs, tpu.
- **Calibration:** hole compensation per printer + material (`printer hole-comp`), kept in
  `~/.config/b123d-print/calibration.toml`.

## Your own printer or material

Not listed, or modified? Add `~/.config/b123d-print/printers/<name>.toml`:

```toml
label = "My Ender 3 with 0.6 nozzle"
bed_x = 220
bed_y = 220
height = 250
nozzle = 0.6
# round_bed = true      # deltas: bed_x is the diameter
# layer_height = 0.2
# max_overhang = 50
```

Materials work the same way in `~/.config/b123d-print/materials/<name>.toml` (`label`, `notes`,
optional `clearance`).

## Sources

- Built-in printers: `src/b123d_print/data/printers_orca.json`, generated by
  `tools/sync_orca_printers.py` from [OrcaSlicer](https://github.com/SoftFever/OrcaSlicer)'s
  printer profiles (one source; other slicers' libraries overlap heavily). Only facts are
  extracted; the OrcaSlicer commit is recorded, and a monthly job refreshes it when OrcaSlicer's
  printer data changes. See [Credits and licenses](../credits.md).
- Custom printers and materials: TOML files in `~/.config/b123d-print/{printers,materials}/`.
- Slicer importers (Bambu Studio, PrusaSlicer, Cura) were considered and dropped: a short TOML
  file covers any printer not in the table.

## Effects

- `fit` check (fails) per printable part; warns when it only fits turned 90°.
- Wall checks default to the printer's minimum wall; the overhang check to its limit.
- `printer(__file__)` in part scripts returns the active profile (or `None` in generic mode);
  `hole_comp(__file__)` picks up the calibration.
- MCP: `list_parts` shows the printer/material, `use_printer` searches and sets them.
